# Вопросы и ответы

**Это нейросеть? Она генерирует сама?**
Нет. YOISAKI AI STUDIO — интерфейс. Картинки генерирует YOISAKI ENGINE в вашем Google Colab на ваших моделях.

**Сайт работает без интернета?**
Сам сайт работает локально на телефоне (`127.0.0.1`) и открывается без интернета. Для генерации нужен интернет:
телефон связывается с Colab через туннель, а Colab читает модели с вашего Drive.

**Это бесплатно?**
Сайт и движок бесплатны. Google Colab Free даёт GPU с ограничениями: время сессии и доступность видеокарты не
гарантированы. Платные тарифы Colab — на ваше усмотрение.

**Нужен ли компьютер?**
Нет. Всё ставится и запускается с Android-телефона.

**Почему папка называется `…V1.4.0_LOCAL_EDITION`, если версия 1.9.2?**
Историческое имя, которое ожидает `update.sh`. Не переименовывайте. Настоящая версия — в разделе GPU
(«Версия студии 1.9.2») и в `./diagnostics.sh`.

**Почему движок 1.8.1, а сайт 1.9.2? Это ошибка?**
Нет. Версии независимы, совместимость определяется протоколом API 1.7.0. Блокнот v1.9.2 содержит проверенный
движок 1.8.1 без изменений кода.

**Какие модели подходят?**
SDXL и Illustrious XL в `.safetensors` (или папка diffusers SDXL). LoRA — под SDXL/Illustrious. SD 1.5, SD 2,
Flux, SD3 не подходят.

**Где мои картинки?**
В галерее сайта — в браузере телефона. Из галереи их можно скачать, скопировать промпт или открыть в редакторе.
Движок держит результат во временной папке Colab, пока сайт не подтвердит сохранение в галерею; на Drive
изображения автоматически не записываются.

**Можно ли закрыть вкладку Colab во время генерации?**
Не рекомендуется: Colab может остановить сессию, и задание прервётся.

**Можно ли поделиться ссылкой движка с другом?**
Нет. В ссылке секретный токен — получивший её сможет пользоваться вашим GPU-сеансом. Пусть друг запустит свой
блокнот.

**Как обновиться?**
`yoisaki update` (или ещё раз команда установки). Настройки, пресеты и галерея сохраняются, неудачное
обновление откатывается. Подробно — [INSTALL_TERMUX.md](INSTALL_TERMUX.md#5-обновление).

**Что такое CloudCompute и Docker в коде?**
Альтернативные способы запуска движка. В этой версии они скрыты по умолчанию и на реальном GPU не испытаны.
Включение: Настройки → Подключения.

**Как сменить язык?**
Настройки → интерфейс → English.

**Где сообщить об ошибке?**
В [Issues](https://github.com/regmop4576-hash/YOISAKI-AI-STUDIO/issues). Приложите вывод `./diagnostics.sh`
и убедитесь, что в тексте нет ссылок с токеном. Об уязвимостях — см. [SECURITY.md](../../SECURITY.md).
