# Модели и LoRA

YOISAKI AI STUDIO не содержит и не скачивает за вас модели. Вы подключаете **свои** файлы через Google Drive;
движок в Colab читает их оттуда.

## Что такое checkpoint и LoRA

- **Checkpoint** — основная модель генерации (несколько гигабайт). Определяет общий стиль и «знания» модели.
  YOISAKI ENGINE работает с **SDXL**-моделями, включая **Illustrious XL** и модели на его основе.
- **LoRA** — небольшое дополнение (обычно десятки–сотни мегабайт), которое «учит» checkpoint персонажу, стилю или
  детали. Применяется поверх checkpoint с весом (силой влияния). LoRA должна быть обучена под SDXL/Illustrious.
- **VAE** — декодер изображения. Необязателен: обычно используется VAE, встроенный в checkpoint.

## Поддерживаемые форматы (по коду движка 1.8.1)

| Тип | Формат | Проверка совместимости |
|---|---|---|
| Checkpoint | `.safetensors` (один файл) или папка diffusers с `model_index.json` | В заголовке должны быть ключи SDXL (`conditioner.embedders.1.*` и `model.diffusion_model.*`); папка diffusers — класс `StableDiffusionXLPipeline`. Иначе модель помечается «Несовместима» и не выбирается. |
| LoRA | `.safetensors` | Если в метаданных указано SD1/SD2/Flux/SD3 — несовместима. Если найдены признаки SDXL — совместима. Иначе — «неизвестно», выбрать можно. |
| VAE | `.safetensors` | Проверяется только структура: «кандидат SDXL VAE». |
| ControlNet | `.safetensors` в `models/controlnet` | Для своих ControlNet; стандартные OpenPose/Depth/Canny скачиваются с Hugging Face при первом использовании. |

Форматы `.ckpt`, `.pt`, `.bin` **не поддерживаются** (движок их не видит). Модели SD 1.5, SD 2, Flux, SD3 не
подходят.

## Где должны лежать файлы

```text
Мой диск (MyDrive)
└── YOISAKI_AI_STUDIO
    └── models
        ├── checkpoints   ← illustriousXL_v01.safetensors …
        ├── loras         ← my_character.safetensors …
        ├── vae           ← (необязательно)
        └── controlnet    ← (необязательно)
```

Внутри папок можно делать подпапки — движок ищет файлы рекурсивно. Путь в Colab:
`/content/drive/MyDrive/YOISAKI_AI_STUDIO/models`.

**Триггер-слова (необязательно).** Рядом с моделью можно положить JSON с тем же именем, например
`my_character.json` для `my_character.safetensors`, с полем `"trigger_words"` (или `"trainedWords"` в формате
Civitai). Движок только читает этот файл и никогда его не изменяет.

## Как обновить список моделей

1. Загрузите файлы на Drive в нужные папки и дождитесь окончания загрузки.
2. В Colab — кнопка **«🔄 ОБНОВИТЬ МОДЕЛИ»** в панели движка.
3. На сайте — **Модели → Модели GPU → «Обновить модели»**.

Список на сайте берётся из ответа движка: показываются только реально найденные файлы, без примеров и
заглушек. Несовместимые модели показываются отдельно («Несовместимые модели: N (не выбираются)»).

## Как выбрать checkpoint

Страница **Генерация** → плитка **«Модель»** → окно каталога с поиском → выберите модель с отметкой
«Совместима». Выбор сохраняется; checkpoint загружается на GPU при первой генерации и между заданиями не
перезагружается.

## Как применить LoRA и настроить веса

Страница **Генерация** → плитка **«LoRA»**:

- можно подключить **до 8 LoRA** одновременно;
- **вес** каждой — от `0` до `2` с шагом `0.05` (начните с `0.6–1.0`);
- переключатель «Включена» временно отключает LoRA, не убирая её из списка;
- **«Теги»** — сохранённые теги/триггеры LoRA. «Вставить в промпт» добавляет их в промпт, «Копировать все» —
  копирует теги всех активных LoRA.

Не забывайте писать триггер-слова LoRA в промпте — без них многие LoRA почти не влияют на результат.

## Как проверить, что модели доступны движку

1. В панели Colab: «Каталог моделей — найден» и счётчик `Checkpoints: N · LoRA: N · VAE: N`.
2. На сайте в разделе **GPU** — строка «Моделей» с числом больше нуля.
3. **Модели → Модели GPU** — ваши файлы с размером и отметкой совместимости.
4. Если списка нет — проверьте, что Drive подключён (панель → «Подключить Drive»), что путь точно
   `MyDrive/YOISAKI_AI_STUDIO/models/...`, что у файлов расширение `.safetensors`, и нажмите «Обновить модели».

## Права и приватность

- В репозиторий и релиз **не добавляются** чужие checkpoint и LoRA, а также ваши личные модели и файлы Drive.
- Используйте только модели, лицензия которых разрешает ваш способ использования. Многие модели на Civitai и
  Hugging Face имеют собственные ограничения (например, на коммерческое использование).
- Не публикуйте модели, на распространение которых у вас нет разрешения.
- Библиотека Google Drive на сайте (вкладка «Google Drive») требует собственного OAuth-клиента — см.
  `docs/INTEGRATIONS_SETUP_RU.md`. Для обычной работы через Colab она не нужна: Colab читает Drive сам.
