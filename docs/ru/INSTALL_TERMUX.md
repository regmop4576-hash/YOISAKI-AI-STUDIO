# Установка YOISAKI AI STUDIO на Android через Termux

Установка — **одной командой**. Не нужно скачивать ZIP через браузер, давать Termux доступ к памяти,
искать архив и распаковывать его: всё это делает официальный установщик
[`install-termux.sh`](../../install-termux.sh).

> **Что проверено.** Установщик прошёл 35 автоматических проверок в чистой имитации Termux (своя `HOME` и
> `PREFIX`, без Node.js, curl и unzip до установки, заглушка `pkg`, локальная копия GitHub Releases API):
> установка, повторный запуск, обновление, докачка, откат, неверная контрольная сумма, восстановление
> повреждённой установки. **На настоящем телефоне с настоящим Termux установщик не проверялся** — если что-то
> пойдёт не так, смотрите [TROUBLESHOOTING.md](TROUBLESHOOTING.md) и пришлите вывод.

## 1. Установите Termux

Только из официальных источников:

- **F-Droid:** <https://f-droid.org/packages/com.termux/>
- **GitHub Releases:** <https://github.com/termux/termux-app/releases> — для Android 7+ файл с `apt-android-7` и
  вашей архитектурой (обычно `arm64-v8a`; если не знаете — `universal`).

Версия из Google Play экспериментальная, разработчики Termux рекомендуют F-Droid или GitHub. Нужен
**Android 7 или новее**. Не смешивайте источники: если Termux уже стоит из другого места, удалите его вместе с
плагинами и установите заново.

## 2. Вставьте одну команду

Откройте Termux, скопируйте команду целиком (долгое нажатие → «Копировать»), вставьте в Termux (долгое нажатие →
«Вставить») и нажмите ввод:

```bash
pkg install -y curl && curl -fsSL https://raw.githubusercontent.com/regmop4576-hash/YOISAKI-AI-STUDIO/main/install-termux.sh | bash
```

Первая часть (`pkg install -y curl`) гарантирует, что есть программа для скачивания; вторая скачивает и
запускает установщик.

### Что произойдёт и что вы увидите

1. **Зависимости.** Если чего-то нет — `pkg update`, `pkg upgrade` и установка `nodejs-lts`, `unzip`, `curl`.
   Первый раз это несколько минут. Вопросы о файлах настроек не появятся — сохраняются ваши текущие.
   → `✔ Зависимости установлены: Node.js v24…` (подходят версии 22–26).
2. **Релиз.** Установщик спрашивает у GitHub последний **стабильный** релиз (не черновик и не pre-release).
   → `✔ Релиз: …, архив YOISAKI_AI_STUDIO_V1.9.2_PIXEL_FANTASY.zip, версия 1.9.2.`
3. **Скачивание** архива (~12 МБ) в `~/.cache/yoisaki-ai-studio`. Если связь оборвётся, загрузка продолжится с
   места остановки — и в этот же раз, и при следующем запуске команды.
4. **Контрольная сумма.** SHA-256 архива сверяется с файлом `SHA256SUMS.txt` из того же релиза (и с контрольной
   суммой, которую публикует сам GitHub). Не совпало — файл удаляется, установка останавливается.
   → `✔ SHA-256 архива совпадает с опубликованным: …`
5. **Проверка архива:** нет абсолютных путей, `../`, символических ссылок и посторонних папок.
6. **Установка** во временную папку и запуск штатного `install.sh` проекта, который проверяет SHA-256 **каждого
   из 553 файлов** (`scripts/verify-package.mjs`). Проверка не отключается.
   → `Обнаружен Android Termux.` · `Проверка целостности файлов: OK (553)` ·
   `Установлено. Локальная production-сборка готова.`
7. Готовая папка переносится на место: `~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION`. Имя историческое, его ожидает
   `update.sh` — не переименовывайте.
8. **Команда `yoisaki`** для запуска, остановки, диагностики и обновления.
9. **Запуск** сайта и проверка, что он отвечает.

В конце:

```text
✔ Сайт отвечает: версия 1.9.2

  Готово! Откройте в браузере телефона:  http://127.0.0.1:3000
```

## 3. Откройте сайт

В любом браузере телефона: **http://127.0.0.1:3000** (или `yoisaki open`).

Вы увидите пиксельную шапку YOISAKI и надпись «GPU отключён» — это нормально, видеокарта подключается через
Google Colab: [GOOGLE_COLAB.md](GOOGLE_COLAB.md).

Иконка на главном экране: меню браузера → «Добавить на главный экран» / «Установить» (в Brave —
«Создать ярлык»).

## 4. Команды

| Команда | Что делает |
|---|---|
| `yoisaki start` | запустить сайт (после перезагрузки телефона — просто откройте Termux и выполните её) |
| `yoisaki stop` | остановить сайт; данные сохраняются |
| `yoisaki restart` | перезапустить |
| `yoisaki status` | диагностика: версия, Node.js, работает ли сервер и из какой папки, журнал без токенов |
| `yoisaki update` | обновить до последнего релиза |
| `yoisaki open` | открыть сайт в браузере (через `termux-open-url`; если её нет — покажет адрес) |
| `yoisaki version` | установленная версия |

Чтобы Android не останавливал сервер в фоне: Настройки Android → Приложения → Termux → Батарея →
«Без ограничений», или `termux-wake-lock`. Порт 3000 занят? `PORT=3001 yoisaki start` и адрес
http://127.0.0.1:3001 (галерея привязана к адресу — используйте один и тот же порт).

## 5. Обновление

```bash
yoisaki update
```

То же самое делает повторный запуск команды установки из шага 2.

- Если установлена последняя версия, **ничего не скачивается**: `✔ Уже установлена последняя версия …`.
- Если вышла новая — скачивается только новый архив (уже скачанный и проверенный берётся из кэша), затем
  запускается `update.sh` **из нового релиза**: он проверяет новую копию, пока старая работает, делает резервные
  копии кода (`~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION.backup-ДАТА`) и данных
  (`~/.local/share/yoisaki-ai-studio.backup-ДАТА`) и запускает новую версию.
- **Если новая версия не запустилась**, автоматически возвращается прежняя и снова запускается:
  `✖ Обновление до … не удалось. Восстановлена версия …, данные не удалялись.`
- Более старый релиз поверх новой версии не ставится (откат вручную — с параметром `--force`).

**Что сохраняется:** настройки, пресеты, теги LoRA, сохранённый GPU-сервер — в `~/.local/share/yoisaki-ai-studio`
(установщик его не трогает, `update.sh` только копирует в резервную копию); **галерея** — в браузере для адреса
http://127.0.0.1:3000 и от обновления не зависит. Не очищайте данные сайта в браузере.

## 6. Безопасный повторный запуск

Команду установки можно запускать сколько угодно раз:

- два установщика одновременно не запустятся (блокировка; «зависшая» блокировка после закрытия Termux снимается
  сама);
- повреждённая установка (не проходит проверку целостности) переносится в
  `~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION.broken-ДАТА` и ставится заново; данные не трогаются;
- прерванное скачивание продолжается; непроверенный файл никогда не устанавливается.

Параметры (после `| bash -s --`, например `… | bash -s -- --no-start`): `--no-start` — не запускать сайт,
`--force` — переустановить тот же релиз.

## 7. Если команда не сработала

| Сообщение | Что делать |
|---|---|
| `curl: (6) Could not resolve host` / `(7) Failed to connect` | Нет интернета или GitHub недоступен. Проверьте связь и повторите. |
| `pkg update не удался` | Сменить зеркало: `termux-change-repo`, затем повторить команду. |
| `CANNOT LINK EXECUTABLE …` | Пакеты обновлены не полностью: `pkg upgrade -y`, затем повторить команду. |
| `Последний релиз нельзя установить … нет нужных файлов` | В последнем релизе на GitHub нет `YOISAKI_AI_STUDIO_V…zip` и `SHA256SUMS.txt`. Это вопрос к автору релиза — см. [RELEASING.md](../RELEASING.md). |
| `SHA-256 архива не совпадает` | Файл повреждён при загрузке или подменён. Повторите команду; если повторяется — не устанавливайте и сообщите в Issues. |
| `Установщик уже запущен` | Дождитесь окончания другого запуска. |
| `Работает другая копия приложения` | Старая копия запущена из другой папки: `cd` в неё, `./stop.sh`, затем `yoisaki start`. |

Остальное — [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## Где что лежит

| Путь | Что это |
|---|---|
| `~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION` | приложение |
| `~/.local/share/yoisaki-ai-studio` | ваши настройки и данные сервера |
| `~/.local/share/yoisaki-installer` | состояние установщика и его копия для `yoisaki update` |
| `~/.cache/yoisaki-ai-studio` | последний проверенный архив (для повторной установки без скачивания) |
| `$PREFIX/bin/yoisaki` | команда `yoisaki` |

<details>
<summary>Ручная установка без установщика (запасной способ)</summary>

1. `pkg update -y && pkg upgrade -y && pkg install -y nodejs-lts unzip` и `termux-setup-storage` (разрешить доступ).
2. Скачайте `YOISAKI_AI_STUDIO_V1.9.2_PIXEL_FANTASY.zip` из
   [Releases](https://github.com/regmop4576-hash/YOISAKI-AI-STUDIO/releases/latest) — именно файл из *Assets*, не
   «Source code»: в исходниках нет готовой сборки `dist/`, и проверка целостности не пройдёт.
3. Проверьте, что файл на месте: `ls ~/storage/downloads/` (ошибка `No such file or directory` значит, что доступ к
   памяти не выдан или файл назван иначе).
4. `cd ~ && unzip -q ~/storage/downloads/YOISAKI_AI_STUDIO_V1.9.2_PIXEL_FANTASY.zip`
5. `cd ~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION && bash install.sh && ./start.sh`
6. Обновление: `bash update.sh ~/storage/downloads/<новый архив>.zip` из папки приложения.

Ручную установку потом можно перевести на установщик: просто выполните команду из шага 2 — он увидит
существующую папку и не будет ставить заново ту же версию.
</details>
