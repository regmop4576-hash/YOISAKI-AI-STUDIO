# Установка YOISAKI AI STUDIO на Android через Termux

Инструкция для тех, у кого есть только телефон. Компьютер не нужен. Каждую команду можно скопировать целиком:
долгое нажатие на блок кода → «Копировать», затем долгое нажатие в окне Termux → «Вставить» → кнопка ввода.

> **Что проверено.** Команды взяты из настоящих `install.sh`, `start.sh`, `stop.sh`, `update.sh` релиза 1.9.2.
> Полный сценарий (распаковка → `install.sh` → `start.sh` → `diagnostics.sh` → `update.sh` → `stop.sh`) выполнен
> в Linux с Node.js 22. **В настоящем Termux на реальном телефоне этот релиз не проверялся** — если что-то
> отличается, смотрите [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## 1. Установите Termux из официального источника

Termux официально распространяется через:

- **F-Droid:** <https://f-droid.org/packages/com.termux/>
- **GitHub Releases:** <https://github.com/termux/termux-app/releases> — для Android 7 и новее берите файл
  с `apt-android-7` и вашей архитектурой (обычно `arm64-v8a`; если не знаете — `universal`).

Версия в Google Play экспериментальная: по словам разработчиков Termux, в ней не хватает функций и есть ошибки,
поэтому они рекомендуют F-Droid или GitHub. Нужен **Android 7 или новее**.

⚠ Не смешивайте источники: сборки из F-Droid, GitHub и Google Play подписаны разными ключами. Если Termux уже
стоит из другого источника, сначала удалите его (и все плагины Termux), потом ставьте заново.

**Что вы увидите:** при первом запуске Termux покажет чёрный экран с текстом «Welcome to Termux!» и строку
ввода с символом `$`.

## 2. Подготовьте Termux

Обновите пакеты и установите Node.js и `unzip`:

```bash
pkg update -y && pkg upgrade -y
```

Если Termux спросит, что делать с файлом настроек (`Configuration file … ==> Package distributor has shipped
an updated version`), нажмите `Enter` — будет выбран вариант по умолчанию.

```bash
pkg install -y nodejs-lts unzip
```

Проверьте версию Node.js:

```bash
node -v
```

**Что вы увидите:** строку вида `v22.…` или `v24.…`. Сайту нужен **Node.js 22–26** (рекомендуется 24 LTS):
`install.sh` проверяет это сам и с другой версией установку не продолжит. Если версия меньше 22, выполните
`pkg upgrade nodejs-lts`.

Дайте Termux доступ к папке «Загрузки»:

```bash
termux-setup-storage
```

**Что вы увидите:** Android спросит разрешение на доступ к файлам — нажмите «Разрешить». После этого папка
«Загрузки» телефона доступна в Termux как `~/storage/downloads`. Проверка:

```bash
ls ~/storage/downloads
```

## 3. Скачайте ZIP из GitHub Releases

Откройте в браузере телефона страницу релизов:
<https://github.com/regmop4576-hash/YOISAKI-AI-STUDIO/releases/latest>

В разделе **Assets** нажмите **`YOISAKI_AI_STUDIO_V1.9.2_PIXEL_FANTASY.zip`** (около 12 МБ). Файл попадёт в
«Загрузки». Не нажимайте «Source code (zip)» — это исходники без готовой сборки, для телефона нужен именно
файл `YOISAKI_AI_STUDIO_V1.9.2_PIXEL_FANTASY.zip`.

Проверьте, что файл скачался полностью:

```bash
ls -l ~/storage/downloads/YOISAKI_AI_STUDIO_V1.9.2_PIXEL_FANTASY.zip
```

**Что вы увидите:** строку с размером `12663390` байт. Для полной проверки можно сравнить контрольную сумму с файлом
`SHA256SUMS.txt` из того же релиза:

```bash
sha256sum ~/storage/downloads/YOISAKI_AI_STUDIO_V1.9.2_PIXEL_FANTASY.zip
```

Ожидается: `9303844fb86d0a3c6b65a6bc76e93c082bb6eace3f29482e0444679667d87449` (сверяйте со строкой в
`SHA256SUMS.txt`).

> Если браузер переименовал файл (например, `… (1).zip`), используйте в командах фактическое имя или удалите
> старую копию и скачайте заново.

## 4. Распакуйте архив

> **Уже есть установленная версия?** Не распаковывайте поверх неё — перейдите к шагу
> [10. Обновление](#10-обновление-до-новой-версии).

Проверьте, что папки ещё нет:

```bash
ls -d ~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION
```

Должно быть `No such file or directory`. Тогда распаковывайте в домашнюю папку Termux:

```bash
cd ~ && unzip -q ~/storage/downloads/YOISAKI_AI_STUDIO_V1.9.2_PIXEL_FANTASY.zip
```

**Что вы увидите:** ничего (флаг `-q` убирает список файлов). Появится папка
`~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION`.

Почему так:

- Приложение должно лежать в **домашней папке Termux** (`~`), а не в `/sdcard` или `~/storage/…`: Android
  запрещает запускать программы из общей памяти, и `install.sh` откажется работать там.
- Имя папки `YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION` историческое и **не связано с версией**. Его ожидает
  `update.sh`, поэтому **не переименовывайте папку**.

## 5. Установите сайт

```bash
cd ~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION && bash install.sh
```

Что делает `install.sh`:

1. Проверяет, что вы в Termux и папка не в общей памяти.
2. Проверяет Node.js (22–26).
3. Запускает `scripts/verify-package.mjs` — сверяет SHA-256 **всех 553 файлов** с `package-manifest.json`.
4. Прописывает путь к bash Termux в первой строке скриптов (`install.sh`, `start.sh`, `stop.sh`, `update.sh`,
   `diagnostics.sh`) и делает их исполняемыми. Проверка целостности учитывает эту замену.
5. Создаёт папку данных `~/.local/share/yoisaki-ai-studio` (права 700).
6. Проверяет, что готовая production-сборка (`dist/`) соответствует исходникам. В релизном ZIP сборка уже есть,
   поэтому **скачивать npm-пакеты не нужно**. Только если сборка не совпадает, скрипт выполнит `npm ci` и
   `npm run build` (нужен интернет).

**Что вы увидите:**

```text
Обнаружен Android Termux.
Проверка целостности файлов: OK (553)
Установлено. Локальная production-сборка готова.
Запуск: ./start.sh
```

Если видите `Файлы приложения отсутствуют или повреждены. Распакуйте полный исходный ZIP заново.` — архив
скачался не полностью или был распакован не туда. **Не отключайте проверку**: удалите папку
(`rm -rf ~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION`), скачайте ZIP заново и повторите шаги 3–5.

## 6. Запустите сервер

```bash
./start.sh
```

**Что вы увидите:**

```text
YOISAKI AI STUDIO v1.9.2 PIXEL FANTASY
Откройте: http://127.0.0.1:3000
Остановка: ./stop.sh
Не закрывайте принудительно Termux во время генерации.
```

Сервер работает в фоне — Termux можно свернуть. Чтобы Android не остановил его, разрешите Termux работу в фоне
(Настройки Android → Приложения → Termux → Батарея → «Без ограничений») или выполните `termux-wake-lock`.

Порт 3000 занят другим приложением? Запустите на другом порту и откройте адрес, который покажет скрипт:

```bash
PORT=3001 ./start.sh
```

## 7. Откройте сайт в браузере

Откройте в любом браузере телефона:

**http://127.0.0.1:3000**

**Что вы увидите:** пиксельную шапку YOISAKI с ночным городом и страницу «Генерация» с надписью
«GPU отключён» — это нормально, GPU подключается отдельно (см. [GOOGLE_COLAB.md](GOOGLE_COLAB.md)).
Проверьте версию: раздел **GPU** → строка «Версия студии **1.9.2**».

Иконка на главном экране: меню браузера → «Добавить на главный экран» / «Установить». В Brave пункт
«Установить» может быть недоступен — используйте «Создать ярлык».

## 8. Остановите сервер

```bash
cd ~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION && ./stop.sh
```

**Что вы увидите:** `Приложение остановлено. Данные сохранены.` Если сервер уже был остановлен —
`Приложение уже остановлено.` Галерея, настройки и пресеты не удаляются.

Не закрывайте Termux принудительно (смахиванием с «Выход») во время генерации.

## 9. Запуск после перезагрузки телефона

После перезагрузки сервер не запускается сам. Откройте Termux и выполните:

```bash
cd ~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION && ./start.sh
```

Если сервер уже работает, скрипт напишет `Сервер уже работает из …` — просто откройте
http://127.0.0.1:3000. Ссылку Colab после перезапуска Colab нужно вставить заново (старый токен недействителен).

Проверить состояние:

```bash
./diagnostics.sh
```

Покажет версию сайта, Node.js, работает ли сервер, из какой папки он запущен и безопасный хвост журнала
(токены скрываются).

## 10. Обновление до новой версии

1. Скачайте новый ZIP со страницы [Releases](https://github.com/regmop4576-hash/YOISAKI-AI-STUDIO/releases/latest)
   в «Загрузки».
2. Запустите обновление **из установленной папки**, указав путь к новому архиву:

```bash
cd ~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION && bash update.sh ~/storage/downloads/YOISAKI_AI_STUDIO_V1.9.2_PIXEL_FANTASY.zip
```

(для следующих версий подставьте имя нового файла).

Что делает `update.sh`, по порядку:

1. Проверяет архив: запрещены абсолютные пути, `../` и символические ссылки.
2. Распаковывает его во временную папку рядом с приложением.
3. В новой копии запускает проверку целостности и `install.sh` — **старая версия в это время продолжает работать**.
4. Останавливает старую версию.
5. Делает резервные копии кода (`~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION.backup-ДАТА`) и данных
   (`~/.local/share/yoisaki-ai-studio.backup-ДАТА`).
6. Ставит новую версию на место старой и запускает её. Если запуск не удался — **автоматически возвращает
   прежнюю версию**; данные не удаляются.

**Что вы увидите в конце:**

```text
Обновлено. Резервная копия кода: /data/data/com.termux/files/home/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION.backup-…
Резервная копия данных (если существовали): …
Откройте http://127.0.0.1:3000/engine и проверьте версию сайта (для этого релиза: 1.9.2 PIXEL FANTASY).
```

3. Обновите страницу в браузере (потяните вниз), чтобы загрузилось новое оформление, и проверьте версию в
   разделе GPU.

Почему не «распаковать поверх»: так смешиваются файлы разных версий, проверка целостности падает, а запущенный
сервер продолжает отдавать старую сборку. `update.sh` решает обе проблемы и не требует повторной установки
с нуля.

**Откат вручную:** `./stop.sh`, затем переименуйте текущую папку и верните папку `…backup-ДАТА` под именем
`YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION`; при необходимости так же верните папку данных.

Старые резервные копии можно удалить, когда убедитесь, что новая версия работает:

```bash
ls -d ~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION.backup-*
```
