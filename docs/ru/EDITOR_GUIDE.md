# Редактор: Inpaint, Img2Img, Face Fix

Раздел **Редактор** работает с уже готовыми изображениями. Все режимы выполняются на подключённом GPU
(см. [GOOGLE_COLAB.md](GOOGLE_COLAB.md)) с checkpoint и LoRA, выбранными на странице «Генерация».
**Исходник никогда не изменяется** — результат сохраняется отдельно в галерею.

Поддерживаются PNG / JPG / WEBP до 25 МБ. Черновик (изображение, маска, рамка лица, режим и параметры)
сохраняется при переходах между страницами и после перезагрузки. Очистить черновики: **Настройки → Редактор**.

## Inpaint — перерисовать часть картинки

1. **Загрузить изображение**.
2. Инструмент **Кисть** — закрасьте область, которую нужно изменить. **Белое редактируется, чёрное
   сохраняется.** **Ластик** стирает маску. Размер кисти задаётся в пикселях исходника.
3. Масштаб — «Увеличить» / «Уменьшить», «Перемещение изображения» — сдвиг холста, «Сбросить вид».
   «Отменить» / «Повторить» работают для маски.
4. Напишите в промпте, что должно появиться в закрашенной области, и настройте **«Сила изменения»**
   (Denoise): меньше — ближе к исходнику, больше — сильнее перерисовка.
5. **Расширенные настройки:**
   - «Область Inpaint»: **Только область маски + контекст** (Crop) — быстрее и детальнее для небольших
     областей; **Весь исходник как контекст** (Full) — лучше для крупных изменений;
   - «Контекст вокруг маски», «Растушёвка маски» — мягкий переход на границе.
6. Запустите задание, затем сравните **«До / После»**. Результат сохраняет исходный размер и альфа-канал.

«Скачать маску PNG» сохраняет маску в полном разрешении (до 6 МБ).

## Img2Img — переработать картинку целиком

Режим **Img2Img** берёт всю картинку как основу. Загрузите исходник, напишите промпт и настройте
**«Сила изменения (Denoise)»**: около `0.3` — лёгкая стилизация, `0.6–0.8` — серьёзная перерисовка с сохранением
композиции. Img2Img доступен и на странице «Генерация».

## Face Fix — исправить лицо

Требует YOISAKI ENGINE **1.8.1** (блокнот v1.9.2 содержит именно его).

1. Загрузите портрет. Лица находятся **автоматически** (CPU-детекторы: аниме-лица и обычные лица).
2. Одно лицо — выбирается само. Несколько — **коснитесь** нужного или нажмите
   «Исправить все найденные лица (N), по очереди».
3. Нажмите **«ИСПРАВИТЬ ЛИЦО»**, затем сравните «До / После» и выберите **«Сохранить результат»** или
   «Оставить оригинал / попробовать снова».

Если лицо не найдено или найдено с низкой уверенностью (часто у антро-персонажей — лиса, летучая мышь,
рептилия, — у профилей и лиц меньше ~30 px) — выделите его **вручную**: проведите пальцем вокруг лица.
Неуверенные варианты автоматически не выбираются («Показать неуверенные»).

Совет из интерфейса: начните с силы `0.25–0.30` и опишите в промпте глаза, мех и форму мордочки. Сохранение
черт не гарантировано. Профиль по умолчанию (сила 0.30, 25 шагов, CFG 5.5) — стартовые значения, на T4 ещё не
подобранные.

## Ограничения

- Inpaint, Face Fix и Img2Img из редактора требуют batch 1 и выключенных ControlNet / Regional Control.
- Нужна совместимая 4-канальная SDXL / Illustrious модель; отдельные inpaint-модели не используются.
- Без подключённого GPU доступны загрузка, маска и ручная рамка, но не обработка.
