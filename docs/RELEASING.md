# Публикация исправленной сборки 1.9.2 — пока НЕ выполнена

Это исправление существующего релиза. Номер сайта остаётся **1.9.2**.
Движок **1.8.1 SMART FACE FIX**, API **1.7.0** и блокноты не изменены.

1. Сначала проверить `STABILITY_REPORT_RU.md`, итоговый ZIP и SHA-256.
2. Получить явное подтверждение владельца на изменения публичных Assets и файла сумм.
3. Обновить исходники и `install-termux.sh` обычным новым коммитом, не переписывая историю.
   Ветка GitHub `main` не содержит исправление ORIGIN_DENIED из исходного ZIP: при переносе
   обязательно сохранить его вместе с `tests/origin-navigation.test.mjs`.
4. В существующем релизе с тегом `Ai` добавить архив
   `YOISAKI_AI_STUDIO_V1.9.2_STABILITY_PIXEL_FANTASY.zip`.
   Существующий ZIP не удалять и не заменять. Новый релиз/тег не создавать и тег `Ai` не перемещать.
5. Обновить существующий `SHA256SUMS.txt` только с разрешения владельца: сохранить строку
   старого ZIP и добавить точную строку нового. Список сумм должен описывать фактические Assets.
   Размещать новый ZIP и суммы согласованно, в короткое окно обслуживания: промежуточное
   несоответствие приведёт к безопасному отказу установщика, а не к установке без проверки.
6. Сверить `digest` и размер нового Asset с локальным ZIP. Проверить `/releases/latest`,
   имя выбранного ZIP и команду установки/обновления. Только после этого объявлять обновление доступным.

Имя важно: старый установщик сортирует архивы через `localeCompare`. Суффикс
`...PIXEL_FANTASY_STABILITY.zip` выбирается ПОСЛЕ старого `...PIXEL_FANTASY.zip` и может
не попасть пользователям. Имя `...V1.9.2_STABILITY_PIXEL_FANTASY.zip` выбирается первым;
это проверено тестом с двумя Assets. Версия, извлекаемая установщиком, остаётся 1.9.2.
Новая копия установщика больше не считает одинаковые номера версий достаточным доказательством
одинаковой сборки, если у ручной установки нет сохранённой SHA-256.

Пока публикация не выполнена, обычный `yoisaki update` скачивает опубликованную старую сборку.
Для проверки пакета до публикации см. инструкцию в отчёте. Не объявляйте его доставленным через GitHub.

Проверка чистой установки и обновления из старого архива:

```bash
bash tests/installer/stability.sh ORIGINAL.zip YOISAKI_AI_STUDIO_V1.9.2_STABILITY_PIXEL_FANTASY.zip
```

Это Linux-имитация Termux с локальным GitHub Releases API, не настоящий Android.
