# Скриншоты v1.9.0 PIXEL FANTASY

Настоящие скриншоты собранного приложения (Chromium через Playwright, реальный локальный сервер). Не сгенерированы
нейросетью. GPU в этих кадрах — **синтетический тестовый движок**: модели «TEST …» и изображения-градиенты являются
тестовыми фикстурами, а не реальными checkpoint или результатами генерации.

`*-390` — телефон 390 × 844 (2×), `*-1280` — ПК 1280 × 900. Номера соответствуют экранам концепта (01–10).
