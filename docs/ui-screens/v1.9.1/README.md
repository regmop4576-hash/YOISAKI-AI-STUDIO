# Скриншоты v1.9.1 (хотфикс шрифтов и PWA)

Настоящие скриншоты собранного приложения: Chromium через Playwright, телефон 412 × 915, реальный локальный сервер.
GPU — **синтетический тестовый движок**: имена моделей и LoRA повторяют ваши файлы только для проверки переноса
длинных названий, изображения-градиенты — тестовые фикстуры. `11-app-icon-512` — иконка приложения из manifest.
Экран Android с ярлыком не снимался: устройства Android в среде проверки нет.
