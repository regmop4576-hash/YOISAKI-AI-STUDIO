# Если что-то не работает

- **Порт занят:** остановите другую копию `./stop.sh`; либо `PORT=3001 ./start.sh` и откройте указанный адрес.
- **Сессия завершилась:** обновите страницу после перезапуска сервера, затем подключите GPU свежей ссылкой.
- **Токен отклонён:** скопируйте всю новую ссылку Colab вместе с `#token=…`; старый токен после перезапуска недействителен.
- **Туннель недоступен / DNS / timeout:** проверьте, что Colab ещё подключён и его панель подтверждает внешнее соединение. Перезапустите движок кнопками и вставьте новую ссылку. Увеличение таймаута само по себе не исправляет туннель.
- **GPU не готов:** выберите T4 в Colab. На телефоне CUDA не устанавливается.
- **Модели пусты:** проверьте доступ Drive и папки checkpoints/loras/vae в YOISAKI_AI_STUDIO/models; нажмите обновление моделей. Файлы не перемещаются и не удаляются автоматически.
- **Несовместимая модель / недостаточно VRAM:** используйте SDXL/Illustrious safetensors, уменьшите разрешение/пакет до 1, временно снимите LoRA/VAE. Точная ошибка доступна в диагностике Colab.
- **Данные повреждены:** сервер пытается восстановить `state.json.bak`, сохраняя повреждённый файл отдельно. Не удаляйте папку данных. Резервная копия может отставать на одну запись.
- **Termux остановлен Android:** снимите ограничения батареи и откройте Termux заново. Обновите страницу приложения.

`./diagnostics.sh` печатает версию Node, состояние сервера и безопасный хвост журнала. Расширенная диагностика Python скрыта в панели notebook. Не публикуйте секретную ссылку подключения и содержимое runtime.json.
