NOT verified (no page text available) and therefore NOT assumed by the implementation:
  - VM-with-Docker vs container instance        -> start-cloudcompute.sh auto-selects docker or native
  - path of the persistent disk (/workspace?)   -> configurable YOISAKI_DATA_ROOT + .yoisaki-data-id persistence probe
  - inbound ports / public networking           -> not needed (outbound Cloudflare quick tunnel only)
  - entrypoint semantics of custom images       -> image CMD runs the launcher; scripts also work inside the image
  - host NVIDIA driver versions                 -> GPU preflight on every start
  - storage price, offline mode, deletion/migration behaviour -> documented as "check in the panel"
