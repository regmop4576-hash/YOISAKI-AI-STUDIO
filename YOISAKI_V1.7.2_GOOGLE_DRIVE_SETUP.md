# YOISAKI AI STUDIO v1.7.2 — подключение Google Drive (однократно, только Android)

Цель: GPU-сервер CloudCompute сам скачивает модели из вашей **приватной** папки
`Мой диск/YOISAKI_AI_STUDIO/models/` (`checkpoints/`, `loras/`, `vae/`).

- Публичные ссылки не нужны.
- ПК не нужен.
- Доступ выдаётся **только на чтение** (`drive.readonly`).

> ⚠ В среде разработки нет настоящего аккаунта Google. Формат команды `rclone authorize` проверен на настоящем rclone. Сохранение токена, его защита и разбор ошибок Google покрыты тестами. **Сам вход в Google и чтение вашего Drive нужно один раз проверить на своём инстансе.**

## Как это устроено

```
Телефон (Termux): rclone authorize ──► браузер телефона: вход в Google, «Разрешить»
        │ печатает JSON-токен
        ▼
Сайт YOISAKI (страница «Модели») ──HTTPS + Bearer──► GPU-сервер: /data/config/rclone/rclone.conf (0600)
                                                           │
                                         rclone lsjson / rclone cat (только чтение)
                                                           ▼
                                            Мой диск/YOISAKI_AI_STUDIO/models
```

- **Почему так.** У сервера CloudCompute нет браузера. У Google нет надёжного входа для такого сервера без собственного OAuth-клиента и публичного адреса возврата.
- Официальный способ rclone для серверов без экрана («remote setup») — получить токен на устройстве с браузером. Это ваш телефон: rclone есть в Termux. Затем токен переносится на сервер.
- Мы не придумывали собственный OAuth-поток в браузере.

## Шаг 2. Получить токен только на чтение

📱 TERMUX
```bash
rclone authorize "drive" "eyJzY29wZSI6ImRyaXZlLnJlYWRvbmx5In0"
```

- Строка `eyJzY29wZSI6ImRyaXZlLnJlYWRvbmx5In0` — это base64 от `{"scope":"drive.readonly"}`. Ровно эту команду печатает сам rclone при настройке Drive с областью `drive.readonly` (проверено на rclone 1.60.1).
- rclone покажет ссылку вида `http://127.0.0.1:53682/auth?state=…`. Откройте её **в браузере этого же телефона**.
- Войдите в Google и нажмите «Разрешить».
- Google вернёт браузер на `127.0.0.1:53682`, то есть в Termux. rclone напечатает:

```
Paste the following into your remote machine --->
{"access_token":"ya29…","token_type":"Bearer","refresh_token":"1//…","expiry":"…"}
<---End paste
```

Скопируйте **строку `{…}` целиком**.

Если браузер пишет «Не удаётся подключиться к 127.0.0.1»: Termux не должен закрываться, пока вы входите в Google. Разрешите Termux работать в фоне и повторите команду.

**Важно:**

- Токен — это ключ к чтению вашего Google Drive. Не отправляйте его в чаты и не публикуйте.
- Termux сохраняет историю команд. Сам токен в команды не вставляйте.

## Шаг 3. Передать токен на сервер — вариант А: через сайт (рекомендуется)

1. GPU-движок CloudCompute 1.7.2 запущен, сайт подключён к нему на странице **GPU** (провайдер CloudCompute).
2. Откройте **Модели → GOOGLE DRIVE AUTO SYNC → «Подключить Google Drive»**.
3. Вставьте строку токена в поле «Токен rclone (JSON)». Это поле пароля, текст скрыт.
4. Нажмите **«Сохранить на сервере и проверить»**.

Что происходит дальше:

1. Токен один раз уходит по HTTPS с Bearer-токеном движка на ваш сервер.
2. Сервер записывает `rclone.conf` с правами 0600 в папку с правами 0700.
3. Сервер сразу запускает «Проверить модели».

Что студия делает с токеном:

- не сохраняет его в `state.json`, localStorage или журналах;
- не показывает его ни в одном ответе;
- поле очищается после отправки.

## Шаг 3. Вариант Б: в терминале сервера

🖥 СЕРВЕР (SSH из Termux или веб-терминал CloudCompute)
```bash
cd /workspace/yoisaki-app

```

- Сразу выполняется проверка доступа.

## Свой OAuth-клиент Google (необязательно)

По умолчанию используется общий OAuth-клиент rclone. Он работает, но разделяет квоты Google с другими пользователями rclone, поэтому список файлов иногда читается медленнее.

Если у вас есть свой клиент («Desktop app» в Google Cloud Console, включён Drive API):

1. 📱 Получите токен с ним:

   ```bash
   rclone authorize "drive" "CLIENT_ID" "CLIENT_SECRET"
   ```

   Укажите при этом область drive.readonly, если rclone спросит.
2. На сайте отметьте «Свой OAuth-клиент Google» и заполните Client ID и Client Secret. Либо на сервере выполните:

   ```bash
   YOISAKI_DRIVE_OWN_CLIENT=1 ./drive-sync-cloudcompute.sh connect
   ```

Токен, полученный с одним клиентом, работает только с этим же клиентом.

## Где хранится и как отозвать

| Что | Где | Защита |
|---|---|---|
| OAuth-токен (access + refresh) | `$YOISAKI_DATA_ROOT/config/rclone/rclone.conf` на GPU-сервере | 0600, папка 0700, владелец — пользователь движка (uid 1000) |
| Состояние синхронизации | `runtime/sync/status.json`, `manifest.json` | 0600; токенов нет |
| Телефон / студия | — | токен не хранится |

Дополнительно:

- `rclone.conf` не отдаётся ни одним маршрутом.
- Его нет в журналах: `yoisaki_redact` скрывает `ya29.`, `1//`, `GOCSPX-`, `"refresh_token"`.
- Его нет в `diagnose.py` и `check-cloudcompute.sh`. Там видно только «подключён: да/нет».
- Шифрование rclone.conf паролем (`RCLONE_CONFIG_PASS`) не используется: пароль пришлось бы хранить на том же диске, и защиты это бы не добавило.

**Отключить:**

- на сайте: кнопка «Отключить Google Drive»;
- или на сервере: `./drive-sync-cloudcompute.sh disconnect`.

Это удаляет копию токена на сервере, но не делает сам токен недействительным. Полный отзыв делается в Google: **myaccount.google.com → Безопасность → Сторонние приложения и сервисы → rclone → Удалить доступ**.

**Удаление инстанса CloudCompute** уничтожает и диск с `rclone.conf`, если диск удаляется вместе с инстансом. Для надёжности после удаления отзовите доступ в Google.

## Что сервер может и не может делать с вашим Drive

- **Может:** читать список файлов и скачивать файлы из `YOISAKI_AI_STUDIO/models`. Папка задаётся на сервере (`YOISAKI_DRIVE_PATH`), не на сайте.
- **Не может:**
  - удалять, изменять, перемещать или загружать файлы на Drive: область `drive.readonly`;
  - выполнить что-то кроме `lsjson` и `cat`: другие команды rclone код синхронизации не запускает (`ALLOWED_COMMANDS`, проверено тестами);
  - выбрать другую папку или другой remote по запросу с сайта.

## Ошибки

| Сообщение | Что делать |
|---|---|
| «Google отклонил авторизацию» | Токен отозван или устарел: повторите шаги 2–3 |
| «Папка или файл не найдены на Google Drive» | Проверьте, что путь именно `Мой диск/YOISAKI_AI_STUDIO/models`. Папка из «Доступные мне» не подходит, сделайте ярлык или копию в «Мой диск». Другой путь: `YOISAKI_DRIVE_PATH` в `config/yoisaki.env` |
| «Google Drive временно ограничил запросы» | Подождите. Для больших библиотек — свой OAuth-клиент |
| «rclone не установлен на сервере» | Пакет 1.7.2: `./start-cloudcompute.sh` (Docker-образ пересоберётся с rclone; в native rclone ставится через apt от root) |
