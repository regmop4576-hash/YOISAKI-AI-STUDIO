# Colab compatibility fix для сайта v1.7.6

Этот архив содержит полный прежний сайт с точечными исправлениями подключения YOISAKI ENGINE 1.7.6 (API 1.7.0) и достоверности модели в Google Drive comparison. Дизайн сохранён. CloudCompute engine не заменён.

Используйте отдельно выданный YOISAKI_ENGINE_V1.7.6_COLAB_COMPATIBILITY.ipynb. Старые ноутбуки внутри исходной папки colab оставлены как прежние артефакты; для этой версии запускайте новый ноутбук.

Обновите сайт обычным способом, сохранив каталог пользовательских данных. Установка Colab по-прежнему не требует Termux, SSH или Docker. Сам сайт продолжает работать прежним способом.

В Colab вручную выбрать GPU, подготовить панель, подключить Drive, запустить движок и скопировать полную ссылку с #token в провайдер Google Colab на сайте. Обновить модели.

Веб-выбор папки Drive не меняет каталог Colab: MyDrive/YOISAKI_AI_STUDIO/models/{checkpoints,loras,vae}. Кнопка переноса файлов /sync относится только к CloudCompute.

Подробный отчёт, матрица и ограничения: YOISAKI_ENGINE_V1.7.6_COLAB_REPORT.md. CUDA/T4 в среде разработки не проверены.
