## Реализованное поведение

GPU и задание имеют раздельные состояния. Время `last_seen_at` относится к последнему
подтверждённому ответу GPU; `last_confirmed_at` — к конкретному заданию. Старый прогресс
не растёт искусственно. Статус старше 45 секунд помечается неподтверждённым; это срок
актуальности снимка, а не лимит генерации. Локальный снимок опрашивается каждые 3 секунды,
проверки удалённого health выполняются отдельно. После сетевого сбоя очередь не делает
один долгий запрос к тому же отключённому серверу для каждой записи подряд.

Потеря связи не означает FAILED. При восстановлении продолжается опрос исходного ID,
изображение записывается в галерею, и только после устойчивого сохранения отправляется ACK.
ACK не ставится впереди получения новых результатов. Повторный POST генерации автоматически
не выполняется. Подтверждённый отказ параметров/занятого GPU и неопределённый сетевой ответ
обрабатываются раздельно. Отмена ожидающего задания требует ответа GPU.

«Проверить и удалить» сохраняет старую защитную проверку. «Убрать локально» позволяет
удалить неподтверждённую запись без связи: это **не отмена GPU**, автоматическое получение
её результата прекращается. Уже сохранённые изображения остаются. Гонка удаления с
незавершённым опросом проверена: запись не возвращается. Запись в момент отправки запроса
нельзя забыть до завершения самой отправки.

Regional использует стабильные машинные значения. При чтении старых настроек `ВЫКЛ`,
`2 ПЕРСОНАЖА`, `3 ПЕРСОНАЖА`, `СВОИ ОБЛАСТИ` переводятся обратно в соответствующие
значения, без изменения содержимого областей. OFF отправляет `regions: []`.
При реальном одновременном включении Regional и ControlNet остаётся предупреждение,
отправка блокируется. Совместная поддержка не имитировалась.

## Безопасное обновление

**Сейчас пакет не опубликован.** Обычный `yoisaki update` до публикации может получить
старый публичный ZIP. Не использовать его как доказательство установки этой исправленной сборки.

После согласованной публикации исправленного архива, сумм и установщика:

```bash
yoisaki update
```

Если команда ещё не установлена, сохраняется однокомандная автоматическая установка:

```bash
pkg install -y curl && curl -fsSL https://raw.githubusercontent.com/regmop4576-hash/YOISAKI-AI-STUDIO/main/install-termux.sh | bash
```

Перед обновлением дождаться доступных результатов и прекратить отправку новых задач.
Обновление готовит и проверяет новую сборку до остановки старой, делает резервные копии
кода и каталога данных, сохраняет OAuth-конфигурацию и откатывает код при неудачном запуске.
Галерея и настройки находятся вне папки приложения; черновики редактора — в IndexedDB
браузера. Не очищать данные Chrome/Termux и использовать прежний адрес
`http://127.0.0.1:3000` (смена origin меняет доступ к браузерным черновикам).

Необязательная проверка скачанного ZIP **до публикации**, для существующей установки с `yoisaki`:
сначала сверить SHA-256 по приложенному `SHA256SUMS_STABILITY.txt`, затем:

```bash
bash "$(yoisaki dir)/update.sh" "$HOME/storage/downloads/YOISAKI_AI_STUDIO_V1.9.2_STABILITY_PIXEL_FANTASY.zip" "$(yoisaki dir)"
```

Путь к Downloads должен соответствовать фактическому месту файла. Это вариант тестирования
неопубликованного пакета, а не замена автоматической установки. После установки открыть
прежний адрес, проверить 1.9.2 и свои данные. Работающий Google Colab обновлять не требуется.
До публикации повторный `yoisaki update` способен вернуть старый публичный пакет.

## Ограничения и оставшаяся проверка

1. **Настоящие Android/Termux и Tesla T4 недоступны в этой среде.** Требуется приёмка на
   телефоне: обновление из GitHub после публикации, открытие с ярлыка, реальная клавиатура,
   уход приложения в фон/перезагрузка телефона и генерация Illustrious на T4.
2. Причина конкретного 20-секундного отсутствия ответа около 94% без журнала той сессии
   Colab не доказана. Исправлена реакция сайта на такой отказ; скорость и устойчивость
   самого GPU по синтетическим тестам не подтверждаются.
3. Если среда Colab удалена вместе с незабранным результатом, сайт не может восстановить
   изображение из процентов. Сохраняется только последний подтверждённый прогресс.
   Для устойчивого хранения на стороне GPU потребовалась бы отдельная работа с движком.
4. Автовосстановление использует прежние ID, провайдера и адрес. Новый runtime/новый
   адрес не доказывает принадлежность прежней задачи; сайт не пересылает генерацию заново.
5. Одновременные Regional Control и ControlNet по-прежнему запрещены текущим контрактом.
   Для совместной реализации нужна отдельная задача для GPU-движка, не это исправление.
6. Локальное удаление неподтверждённой записи не доказывает отмену на GPU и прекращает
   автоматическую загрузку именно её результата. Уже сохранённая галерея остаётся.
7. Перезапуск телефона, Android battery restrictions и реальная доставка иконки ярлыка
   не могут считаться подтверждёнными Linux/Chromium-эмуляцией.

Ни одна правка движка не потребовалась для воспроизведённых дефектов сайта и не выполнялась.
План публикации без переноса тега и без замены старого ZIP находится в `docs/RELEASING.md`.
Реально опубликованные в рамках этой работы файлы: **ни одного**.
