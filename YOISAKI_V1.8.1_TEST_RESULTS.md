## Новые тесты

**`tests/test_v181_facefix.py`** (реальные модели OpenCV и tiny SDXL на CPU):

1. Модели проверяются по SHA-256 и загружаются лениво; белый и градиентный холсты — 0 лиц.
2. Подменённый хеш или отсутствующий файл модели → понятная ошибка, детекция не выполняется.
3. Правила выбора: одно уверенное лицо — автовыбор; два — выбор обязателен; неуверенное — никогда не автовыбирается; слияние двух детекторов (noisy-OR); воспроизводимые id, привязанные к изображению; обрезка рамки краем.
4. Валидация `/facefix/detect` и выбора: неизвестный/повторный/пустой id, неверный детектор/порог, лишние поля.
5. Маска: овал оставляет углы рамки, расширение, край изображения; рабочий размер по пропорциям.
6. Композит с овальной маской: пиксели вне маски и альфа точно сохранены; без полей letterbox.
7. Контракт `AdapterRequest`: ручная рамка XOR выбранные лица, проверка `face_options`, прогресс = шаги × число лиц.
8. HTTP: авторизация 401, ошибка 422, capability `auto_facefix`, детекция отвечает **пока GPU-воркер занят**, задача с двумя лицами, неизвестный id в `/generate` → 422.
9. Настоящий Diffusers `StableDiffusionXLInpaintPipeline` (tiny, случайные веса): 4 задачи по 2 лица, отмена во втором лице, восстановление; общие модули, неизменный объём параметров, отсутствие удерживаемых view; ресурсы — `validation/cpu-facefix-resources.json`.

**`tests/v181-facefix.test.mjs`** (Node): сохранение запроса без изменений и удаление исходника из истории; отклонение неверных выборов/опций/режимов; валидация ответа детектора (рамки внутри изображения, формат id, выбранный id существует); совместимость 1.8.1 и `supportsAutoFaceFix`; локальный сервер проксирует детекцию для движка 1.8.1 и **не отправляет** `face_detection`/`face_options` движку 1.8.0 (тот молча проигнорировал бы неизвестные поля), а ручной Face Fix v1.8.0 продолжает работать.

**`tests/v181-facefix-browser.mjs`** (Chromium, 390×844 и 360×780, isMobile + touch; **GPU-ответы синтетические**):

- Расширенные параметры скрыты по умолчанию.
- Одно лицо: автовыбор, «Исправить лицо» без рамки; запрос содержит выбранный id, овальную маску, 1024, 25 шагов, CFG 5.5, силу 0.3, авто-растушёвку; промпты, LoRA и checkpoint без изменений; детекция и исправление используют одни и те же байты исходника.
- Результат: «До / После», скачивание совпадает с ответом движка, запись в галерее, в истории нет base64-исходника.
- Два лица: ничего не выбрано молча, кнопка неактивна; зона касания ≥ 44 px; касание выбирает лицо без прокрутки страницы; «Исправить все» отправляет оба id.
- Нет уверенного лица: сообщение, автоматической отправки нет; неуверенный вариант виден только по запросу и не выбран; ручное выделение пальцем без прокрутки страницы.
- Расширенные настройки работают (смена детектора → повторный поиск); настройки страницы Generate не изменяются.
- Нет горизонтального переполнения на 390 и 360 px; нет ошибок страницы.

Изменён `tests/v180-editor-browser.mjs`: классический редактор Face Fix теперь открывается через «Расширенные настройки»; при движке 1.8.0 проверяется предупреждение о совместимости.
