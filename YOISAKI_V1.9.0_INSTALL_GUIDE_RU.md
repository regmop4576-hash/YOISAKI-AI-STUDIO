# YOISAKI AI STUDIO v1.9.0 PIXEL FANTASY — обновление в Termux

Движок, блокнот Colab и формат данных не менялись: обновляется только сайт. Галерея, настройки, пресеты, теги LoRA,
вход Google и сохранённый сервер GPU сохраняются, `update.sh` перед заменой делает резервные копии кода и данных.

## Обновление существующей установки

1. Скачайте `YOISAKI_AI_STUDIO_V1.9.0_PIXEL_FANTASY.zip` в папку «Загрузки» телефона.
2. В Termux (один раз) дайте доступ к памяти: `termux-setup-storage`.
3. Запустите обновление из установленной папки:

```bash
cd ~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION
bash update.sh ~/storage/downloads/YOISAKI_AI_STUDIO_V1.9.0_PIXEL_FANTASY.zip
```

Скрипт проверит целостность всех файлов (SHA-256), соберёт сайт, остановит старую версию, сохранит резервные
копии и запустит новую. Если запуск не удастся, прежняя версия восстанавливается автоматически.

4. Откройте `http://127.0.0.1:3000/engine` и убедитесь, что внизу карточки GPU указано `1.9.0`.
   В браузере обновите страницу (потяните вниз), чтобы загрузить новое оформление.

## Новая установка

```bash
cd ~ && unzip -q ~/storage/downloads/YOISAKI_AI_STUDIO_V1.9.0_PIXEL_FANTASY.zip
cd YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION && bash install.sh && ./start.sh
```

## Что важно знать

- Папку приложения держите в домашней папке Termux (`~`), не в общей памяти (`/sdcard`).
- Проверку целостности не отключайте: если она не проходит, распакуйте архив заново.
- CloudCompute по умолчанию скрыт (не прошёл испытаний на реальном GPU). Включение: Настройки → Подключения.
- Черновики редактора (загруженные картинки, маски) хранятся в браузере; очистить — Настройки → Редактор.
- Откат: остановите приложение (`bash stop.sh`) и верните папку `…backup-ДАТА`, созданную при обновлении.
