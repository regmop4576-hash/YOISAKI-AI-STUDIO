# YOISAKI v1.8.1 SMART FACE FIX — отчёт по детекции лиц

Дата: 30 октября 2026. Сайт 1.8.1, Colab-движок 1.8.1, API 1.7.0.

Отчёт разделяет три вещи: **найдено ли лицо** (проверено на CPU), **верно ли выбрана область** (проверено визуально и тестами) и **хорошо ли исправлено лицо** (не проверено: нет T4 и полноразмерного checkpoint).

## 1. Исследование существующих решений

| Проект | Что взято как идея | Лицензия | Решение |
|---|---|---|---|
| ADetailer (Bing-su/adetailer) | Цепочка детекция → маска → inpaint только области → композит. Дефолты из `adetailer/args.py`: confidence 0.3, dilate/erode 4, mask blur 4, denoise 0.4, inpaint only masked = true, padding 32 px, inpaint 512 px; фильтры min/max area ratio и top-k; merge-режимы масок | AGPL-3.0 | Код **не копировался**. Использованы только общие принципы. |
| ComfyUI Impact Pack, FaceDetailer | BBOX/SEGS, crop_factor (контекст), guide_size (рабочий размер), feather, denoise, отдельная обработка каждого SEG, возврат в исходник. Дефолты из `impact_pack.py`: guide_size 512, denoise 0.5, feather 5, drop_size 10 | GPL-3.0; Ultralytics-детекторы вынесены в отдельный Subpack | Код и фреймворк **не устанавливались**. |
| Fuyucch1/yolov8_animeface | YOLOv8 аниме-лица (обучен на 10 000 изображений safebooru) | Репозиторий AGPL-3.0; требует Ultralytics (AGPL-3.0); лицензия весов отдельно не указана; права на датасет не описаны | **Не интегрирован**: AGPL-обязательства для всей сетевой службы и неясные права на веса/данные. |
| deepghs anime face detection (Hugging Face) | Возможная альтернатива YOLO | — | Hugging Face недоступен из среды разработки (HTTP 403 на прокси); **не оценивался**. |
| nagadomi/lbpcascade_animeface | LBP-каскад для аниме-лиц, 247 КБ, OpenCV | MIT (уведомление внутри XML) | **Интегрирован** как детектор `anime`. |
| OpenCV Zoo YuNet 2023mar | Лёгкий CNN-детектор лиц, 233 КБ ONNX, OpenCV `FaceDetectorYN` | MIT (Shiqi Yu) | **Интегрирован** как детектор `human`. |

Обоснование: оба выбранных детектора — MIT, крошечные, работают на CPU через уже закреплённый `opencv-python-headless==4.11.0.86` (Apache-2.0), без новых pip-зависимостей, без Ultralytics/AGPL и без GPU. Файлы вложены в движок без изменений, проверяются по SHA-256 перед загрузкой (`engine/inference/face_models/LICENSES.md`).

Реализация Civitai неизвестна; этот релиз **не воспроизводит** её и не заявляет эквивалентного качества.

## 2. Устройство

`engine/inference/facedetect.py` — модульная абстракция:

- `detect(image, detector, min_confidence)` → документ: `faces[]` с `id`, `x`, `y`, `width`, `height` (целые пиксели EXIF-ориентированного исходника), `confidence` (0–1), `detector`, `label='face'`, `auto_selectable`; плюс `image{width,height}`, `selected`, `selection_required`, `detectors_run`, `duration_ms`. Тензоры детекторов наружу не выходят.
- `auto` = аниме-LBP (вход до 1600 px по длинной стороне, minSize 24) + YuNet (масштабы 640 и 1280 px, т.к. YuNet видит лица ~10–300 px). Перекрывающиеся рамки разных детекторов сливаются: рамка — взвешенная по уверенности, уверенность — noisy-OR (согласие двух детекторов повышает её).
- LBP не даёт вероятности: вес последней стадии каскада переводится логистикой `1/(1+e^(-1.5·(w−0.5)))`, откалиброванной на наборе ниже. Это эвристика, а не вероятность.
- Порог показа 0.35 (настраивается 0.05–0.95). **Автовыбор** — только если ровно одно лицо с уверенностью ≥ 0.6. Иначе — выбор пользователем. Неуверенные (< 0.6) варианты скрыты по умолчанию и никогда не выбираются автоматически.
- Максимум 12 лиц (крупнейшие первыми). Рамки обрезаются краями изображения; лица меньше 8 px отбрасываются.
- `id` = SHA-256 от версии, пикселей изображения, детектора и рамки. При `/generate` движок **повторно** запускает детекцию на точном исходнике задания и принимает только существующие `id`; координаты от клиента для автоматического режима не используются.

## 4. Антро, чиби, профили — что НЕ проверено

Авторизованные референсы пользователя (лиса, летучая мышь, рептилия, профиль, чиби, полный рост) **не были предоставлены**, а внешние фотобанки недоступны из среды. Поэтому:

| Категория | Статус |
|---|---|
| Аниме-человек | проверено (выше) |
| Два лица | проверено (3 аниме-изображения + синтетический UI-тест) |
| Маленькое лицо в полный рост | проверено синтетически (уменьшенные портреты в большом холсте) |
| Без лица | проверено (8 изображений) |
| Чиби | частично: t01, t04 (чиби-пропорции) — найдены LBP уверенно |
| Профиль | **не проверено** (нет изображений) |
| Антро лиса / летучая мышь / рептилия | **не проверено**. Оба детектора обучены на человеческих/аниме-человеческих лицах; морда реального животного (бабуин) не найдена. Ожидается частый промах на мордах с выраженной мордой/клювом/чешуёй — в этом случае сайт сообщает «Лицо не найдено» и предлагает ручное выделение. |

Для своих персонажей добавьте в Colab ячейку после «ПОДГОТОВИТЬ ПАНЕЛЬ»:
`!python /content/yoisaki_engine/face_eval.py /content/drive/MyDrive/ПАПКА_С_РЕФЕРЕНСАМИ`
Скрипт (`engine/face_eval.py`) только печатает найденные рамки и уверенность; ничего не записывает, никуда не отправляет и не запускает SDXL. Он показывает, какие персонажи находятся автоматически.

## 5. Маска и композит

- Из рамки строится **овал** (не прямоугольник), расширенный на 8 % размера рамки с каждой стороны и обрезанный краями изображения. Углы рамки — волосы, уши, фон — не редактируются (проверено тестом и визуально на оценочных портретах: кошачьи уши остаются вне маски).
- Растушёвка внутрь существующим `feather_mask` (ноль на границе, наружу не расширяется); по умолчанию 8 % меньшей стороны лица, 2–32 px.
- Контекст (padding) 0.5 размера маски с каждой стороны (≈ crop_factor 2 у FaceDetailer); обрезается краями.
- Рабочий размер — по пропорциям crop внутри 1024×1024 (кратно 8), **без белых полей letterbox**; при слишком вытянутом crop — прежний letterbox.
- Композит: вне поддержки маски пиксели и альфа-канал исходника сохраняются точно (тесты сравнивают массивы).
- Ограничения: точной сегментации нет — маска консервативная по рамке; у лица на краю изображения растушёвка гасит редактирование у самой границы; рука перед подбородком попадает в маску; при «исправить все» второе лицо обрабатывается уже поверх результата первого.

## 6. Качество исправления

Не измерялось: нет T4 и полноразмерного Illustrious. Значения профиля (сила 0.30, 25 шагов, CFG 5.5, до 1024 px) — **стартовые**, выбраны по причинам: SDXL обучен около 1024 px (v1.8.0 по умолчанию работал в 512×512 с полями — вероятная причина слабых результатов); низкая сила снижает риск потери черт; ADetailer/FaceDetailer используют 0.4–0.5 — выше, поэтому при недостаточном эффекте пользователь может поднять ползунок до 0.6. Подбор на T4 и сравнение с Civitai остаются открытыми задачами.
