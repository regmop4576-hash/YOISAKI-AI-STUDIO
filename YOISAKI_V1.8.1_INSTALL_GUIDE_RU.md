# YOISAKI AI STUDIO v1.8.1 SMART FACE FIX — установка и обновление (Android / Termux)

Нужно два файла:

- `YOISAKI_AI_STUDIO_V1.8.1_SMART_FACE_FIX.zip` — сайт для телефона;
- `YOISAKI_ENGINE_V1.8.1_SMART_FACE_FIX.ipynb` — движок для Google Colab (он же лежит в архиве в папке `colab/`).

Ваши настройки, галерея, история и Google-вход хранятся отдельно от папки приложения (`~/.local/share/yoisaki-ai-studio`) и при обновлении не удаляются. Старая версия кода сохраняется резервной копией.

## 1. Скопировать архив в Termux

Android не разрешает запускать приложение из «Загрузок», поэтому архив сначала копируется в домашнюю папку Termux.

```bash
termux-setup-storage
cp ~/storage/downloads/YOISAKI_AI_STUDIO_V1.8.1_SMART_FACE_FIX.zip ~/
```

(`termux-setup-storage` нужен один раз; разрешите доступ к файлам.)

Необязательная проверка целостности скачанного файла — сравните с `SHA256SUMS.txt`, который приложен рядом с архивом:

```bash
sha256sum ~/YOISAKI_AI_STUDIO_V1.8.1_SMART_FACE_FIX.zip
```

## 2А. Обновление уже установленного сайта (рекомендуется)

Найдите папку установленного приложения (обычно `~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION` — историческое имя, это нормально):

```bash
ls ~
cd ~/YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION
bash update.sh ~/YOISAKI_AI_STUDIO_V1.8.1_SMART_FACE_FIX.zip
```

Что делает `update.sh`, по порядку:

1. Распаковывает новый архив во временную папку и **проверяет SHA-256 всех файлов** (`verify-package`) и production-сборку. Если что-то не совпадает — обновление прекращается, работающая версия не тронута.
2. Останавливает старую версию.
3. Делает резервные копии: кода (`…_LOCAL_EDITION.backup-ДАТА`) и данных (`yoisaki-ai-studio.backup-ДАТА`).
4. Ставит новую версию на место старой и запускает её. Если запуск не удался — автоматически возвращает прежний код.

После сообщения «Обновлено» откройте в браузере `http://127.0.0.1:3000/engine` — внизу должна быть версия **1.8.1**.

## 2Б. Установка в новую папку (если сайта ещё нет или нужно не трогать старый)

```bash
mkdir -p ~/yoisaki-181 && cd ~/yoisaki-181
unzip -q ~/YOISAKI_AI_STUDIO_V1.8.1_SMART_FACE_FIX.zip
cd YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION
bash install.sh
bash start.sh
```

Если старая версия запущена, сначала остановите её из её папки: `bash stop.sh`. Обе версии используют одни и те же данные; одновременно запускайте только одну.

Готовая сборка уже внутри архива: npm и компилятор не нужны. Нужен Node.js 22–26 (`pkg install nodejs-lts`, если `install.sh` попросит).

## 3. Если установка сообщает об ошибке целостности

Сообщение «Файлы приложения отсутствуют или повреждены» с перечнем файлов означает, что архив скачался не полностью или был изменён. Ничего не отключайте — скачайте архив заново и сравните `sha256sum` с `SHA256SUMS.txt`. Проверка в v1.8.1 выполнялась по точному выпущенному ZIP после чистой распаковки, включая имитацию путей Termux (см. TEST_RESULTS) — ошибка v1.8.0 с устаревшим манифестом исключена тем же способом сборки.

## 4. Новый движок в Google Colab

1. Откройте `YOISAKI_ENGINE_V1.8.1_SMART_FACE_FIX.ipynb` в Google Colab (Файл → Загрузить блокнот).
2. Среда выполнения → Сменить среду выполнения → **T4 GPU**.
3. Запустите ячейку **«1. ПОДГОТОВИТЬ ПАНЕЛЬ»** (несколько минут), подключите Google Drive.
4. Нажмите **«ЗАПУСТИТЬ ДВИЖОК»**, скопируйте защищённую ссылку целиком.
5. На сайте: раздел **GPU** → вставьте ссылку → «Подключиться».

Старый блокнот v1.8.0 тоже подключится, но автоматический поиск лиц будет недоступен: сайт покажет предупреждение и оставит ручное выделение.

## 5. Как пользоваться Smart Face Fix

1. На странице **Generate** выберите Checkpoint, LoRA и напишите Positive Prompt с описанием персонажа (глаза, мех, форма мордочки) — Face Fix использует их как есть.
2. **Редактор → FACE FIX** → «Загрузить изображение».
3. Лицо найдётся само. Если лиц несколько — коснитесь нужного или отметьте «Исправить все найденные лица».
4. Если лицо не найдено (часто у антро-морд) — проведите пальцем по изображению вокруг лица.
5. Ползунок «Сила исправления»: 0.3 — бережно; больше — сильнее перерисовка.
6. **«Исправить лицо»** → ползунок «До / После» → «Сохранить результат». Не понравилось — «Оставить оригинал / попробовать снова». Результат также сохраняется в галерею.

Остальные параметры — в «Расширенных настройках» (свёрнуты). Там же «Классический редактор Face Fix (v1.8.0)».

## 6. Откат

Если что-то не так после обновления через `update.sh`:

```bash
cd ~
bash YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION/stop.sh
mv YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION.v181
mv YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION.backup-ДАТА YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION
bash YOISAKI_AI_STUDIO_V1.4.0_LOCAL_EDITION/start.sh
```

(`ДАТА` — из сообщения `update.sh`; список: `ls ~ | grep backup`.)
